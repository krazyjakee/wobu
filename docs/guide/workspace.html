Mode rail

Icon-only, always visible on the far left. Five destinations, which keeps the top bar clean and makes switching muscle memory:

Library The world tree and the node editor — the screen above. Your default.
Board A freeform pan-and-zoom mood board. Drag an image onto a node to make it a reference.
Forge Generation promoted to full width with a large result grid, for iterating hard on one subject.
Assets Every image in the project, filterable by node, role, and whether it was generated or imported.
Settings Providers and models, storage, editor behaviour, appearance, diagnostics.

Title bar

A custom title bar, so the chrome matches on Linux, macOS and Windows. Left to right: the wobu mark, the project picker (click the project name to see its full path or close it), a read-only badge when the folder isn't writable, and the influence breadcrumb for the selected node — Species / Vashk / Kael Vantris. Every crumb is clickable and jumps to that node. On the right, ⌘K search and the settings gear.

Navigator

272px, resizable, collapsible with [.

  • Filter box at the top matches node names and one-line summaries. For searching inside notes and descriptions, use the command palette instead.
  • Two pinned singletons — Style Guide and World Canon — sit above the rule, because they root every influence stack.
  • Collapsible groups per kind, each nesting by parent. Regions contain cities contain districts.
  • Drag to re-parent. Dropping a node onto another moves it in the hierarchy — and therefore changes what it inherits.
  • Right-click for New, New child, Duplicate and Delete. Singletons can't be duplicated or deleted.
  • Status dots. A node whose description has gone stale gets a small dot; a node someone else is editing gets a presence dot.
Broken files

If a file in the project folder can't be parsed — a sync client mangled it, or a hand edit broke the frontmatter — Wobu surfaces it in the navigator with the parse error, and offers Reveal and Reload. It never silently skips a file and it never overwrites one it couldn't read.

Editor

The fluid centre column, and the place you actually author.

Sticky header

Inline-editable name, a colour-coded kind badge, a stale badge when the description has drifted from the notes, the influence breadcrumb, and the Enhance button in the violet AI accent. An autosave indicator sits alongside — Wobu saves as you type, on a delay you can tune in Settings.

Tabs

Five tabs, reachable with ⌘1–⌘5:

⌘1 Notes The centre of gravity: raw notes on the left, enhanced structured description on the right.
⌘2 References Image grid; each tile carries a role chip and a weight. Drag-drop or paste to add.
⌘3 Concepts Generated art for this entity. Hover for prompt and seed; pin to promote a result into References.
⌘4 3D Turnaround sheets and generated meshes, with an inline viewer.
⌘5 Relations The links this node has, and its backlinks — "3 characters inherit from this".

The Notes split

Two columns with the Enhance button between them. Left is yours, right is the machine's. That spatial split is the mental model of the whole app: Wobu never writes into your column, and you can always edit its column. Covered in Notes & Enhance.

Inspector

352px on the right, collapsible with ]. This is the differentiating panel — an ordered list of influence layers from outermost to innermost, the compiled prompt beneath it, and the shot controls beneath that.

style world species culture place subject

Each layer card carries a colour dot, the source node, a fragment and reference count, a weight slider, a mute toggle, and an expander showing the exact text and images it contributes. The full explanation is in The Influence Stack.

The one rule worth internalising

Muting or reweighting in the Inspector affects this generation only. It never edits your world. Editing the world happens in the editor. If you find yourself muting the same layer every time, that's a signal to go fix the node.

Status bar

26px along the bottom, all read-only: backend health, project name and path, active image model, job queue depth, active LLM, and the last generation time. When the project sits on a network share it says so and shows the poll interval; when the folder is read-only it says that too.

Command palette

⌘K from anywhere. It searches in two phases — node names match instantly, then full-text hits from inside notes and descriptions arrive a moment later, ranked. Results are grouped:

  • Nodes — jump straight to an entity, switching to Library mode if you were somewhere else.
  • In notes and descriptions — full-text hits, for when you remember a phrase but not which node it's on.
  • Commands — New node, toggle navigator, toggle inspector.

Arrow keys cycle, Enter picks, Esc closes.

Appearance

Dark-first, with neutral cool greys so that concept art — the actual content — carries all the colour. There is one warm accent for things you do and one violet accent reserved exclusively for things the machine does, so "an AI action is about to happen" is always legible at a glance. Base font size is 13px because this is a dense tool UI; if that's too tight, Settings has a UI scale slider from 80% to 150%.
